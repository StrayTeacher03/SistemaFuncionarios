# Sistema de Cadastro de Funcionários
Com esse simples programa podemos simular a criação e gerencia de um departamento e seus funcionários

## É Usado:
[JDK](https://www.oracle.com/br/java/technologies/downloads/#java21)

[VSCode](https://code.visualstudio.com/Download)

## Como Executar:
```java
# No VSCode clique no botão f5
```

## Classes:
A classe Funcionário serve para gerenciar os objetos dos funcionários, permitindo contratar, demitir, aplicar reajuste e etc

A classe Departamento serve para Gerenciar departamentos, adicionando funcionários, listando ou pegando a folha salarial dos ativos

A classe TesteSistema é onde o programa roda e é testado
